# 🔎 Live Query Filter System

A full-stack Live Query Filter System that provides real-time product searching, multi-category filtering, debounced API requests, loading states, and pagination.

## 🚀 Features

- 🔍 Live product search
- ⏱️ Debounced search to reduce unnecessary API requests
- 🏷️ Multi-category filtering
- 📄 Pagination
- 🌐 REST API with query parameters
- ⏳ Loading state
- 📱 Responsive product grid
- 🔄 Dynamic API-based results
- ❌ No-results handling

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- Fetch API
- Live Server

### Backend
- Node.js
- Express.js
- CORS
- REST API
